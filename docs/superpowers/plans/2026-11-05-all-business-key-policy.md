## Decision and boundary

Use optional `businessDataPolicy: "all-personal-business-v1"` in Better Auth metadata, alongside the unchanged space binding and explicit permissions. Missing policy means the exact legacy scoped grant. Future ordinary business modules can join only through a reviewed server operation registry and current readiness. Do not use a wildcard permission, default permission change, client-supplied registry, or a browser session as Agent authority. Account/security/key/system/payment/order/irreversible operations never join this policy.

The candidate contains a tested authorization resolver, proposed0016 policy-aware SQL, an opt-in issuer adapter and owner UI selection/readback. Proposed0016 depends only on0011/0014 and deliberately does not consume the reserved calendar0015. The existing private signer/controller remains a separate package; its deployed identity has not been changed.
