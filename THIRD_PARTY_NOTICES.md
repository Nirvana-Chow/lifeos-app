## Locked dependencies

`third-party/dependencies.json` records package/version, official registry source, integrity and declared license for the single npm lock, with license paths found in inspected distributions. This source repository does not vendor node_modules, compiled application bundles, native dependencies or images. Optional platform distributions vary by operating system.

Installing or redistributing dependencies continues to require their original notices and applicable terms. The index does not replace complete upstream terms. Any later binary, bundle or image release must review actual shipped contents, including libvips, resvg, lightningcss and other native or bundled dependencies.
