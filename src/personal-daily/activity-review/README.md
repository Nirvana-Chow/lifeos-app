# 日常每日活动热力图评审原型

本原型接续 LifeOS「日常单日视图」。映射到日记和周期回看的 `LO-JOURNAL-001`、`LO-REPORT-001`，以及交付进度和固定版本读回的 `LO-REQ-001`、`LO-VERSION-001`。映射依据在仓库现有日记覆盖计划与 PersonalAgent 需求覆盖表。原需求记录和现有任务状态保留。

## 复现

使用项目已锁定的 Playwright 和本机 Chromium。原型本身是静态 HTML、CSS、ES 模块，无额外依赖。

```sh
python3 -m http.server --bind 127.0.0.1 4173 --directory src/personal-daily/activity-review
TZ=America/Los_Angeles node --test src/personal-daily/activity-review/activity.test.mjs
node src/personal-daily/activity-review/check-browser.mjs /tmp/lifeos-activity-evidence
```

本地评审地址为 `http://127.0.0.1:4173/`。浏览器验证会拦截请求并从当前目录回放资产，不需要启动本地服务。可用 `CHROMIUM_PATH` 选择 Chromium 可执行文件。

## 验收

- 顶部时间维度为日、周、月、季度、年。日只显示原文或成果明细；其余使用同一网格及期间总览，周从周一开始，月、季度、年按自然边界。热力图只提供「记录」和「开发」，切换时保留所选日期。记录详情保留 Memos 和日记来源标签及其原文。日期可点击，也可用方向键移焦和 Enter 打开，另有原生日期输入。格子和图例提供数字、文字或图案提示。三组活动量使用各自色阶。
- 以 `Asia/Shanghai` 归属带明确偏移的时刻，已保存的本地纯日期沿用来源日期。样例观察日为 2026-11-24。11 月 22 日覆盖未知、23 日未获授权、21 日确认零条、24 日有记录。之后的日期标记「未到日期」，不计作已覆盖或零。前两种状态不展示记录也不计零。若只有一种记录来源可核对，日格标明部分覆盖，并只展示可核来源。无日记、无标题 Memos 和多段正文均有合成样例。
- 开发按当天有核对证据的成果 ID 去重。当天同一成果的多个阶段只计一次，阶段保留在详情。季度成果按 ID 跨天去重，各阶段分别按成果去重。代码候选、合并、实际运行版本和验收各自依赖可核对证据，未核证的记录不计入。统计不使用消息数、token、聊天时长、裸提交数或公司仓库数据。
- 手机上使用同一个桌面页面、内容、布局和入口，浏览器缩放和拖动保留。先以触屏模拟核对，浏览器缩放和横向触摸拖动可以模拟验证，实体手机双指缩放留待实际设备验收。下一步及回退仅展开样例说明，原型没有执行入口。

## 未来来源与回退

静态评审入口只使用内置合成数据。热力图按来源、本地日期、已去重计数与覆盖状态展示结果。当日详情显示已获授权的标题和原记录引用。开发数据限于已有交付证据，使用成果 ID、阶段、带时区的时刻和证据引用。来源不完整、无法证明覆盖或无读取权时保留对应状态。

当前可回退边界为独立原型目录。评审不通过时，保留或舍弃本增量补丁，原「日常」单日候选树仍可用。日后正式接线失败，由既有发布负责人按项目流程回到上一经验证版本，并读回运行版本及恢复结果。

主会话负责接手评审结果和确认下一执行者。确认进入正式开发后，执行者在原任务和已有合并门内完成只读来源契约与真实设备复核。正式发布由既有发布负责人接续并读回运行版本，Dan 验收实际使用体验。

## 站内入口与来源

现有日记页的「查看每日活动」进入 `/personal/activity`。打开日记原文后可选择「查看当天活动」，以 `/personal/activity?date=YYYY-MM-DD` 定位到日视图。热力图内切换时间维度或类别时保留所选日期。`journal-source.ts` 复用本人日记 GET 契约和前后绑定校验。现有快照包含正文，活动页只投影已核对的 ID、标题、来源引用和记录日期。正文仍在既有原记录入口查看。

完整当前快照只能证明读到了哪些记录。存在日记的日期为「部分覆盖」，相邻无条目的日期为「覆盖未知」。日记未获授权、绑定变更或响应截断时仍可浏览日期与已有开发凭据，日记详情清空。Memos 复用站内日记快照中已确认关联随手记、思考或 Memos 主题的记录。缺失或过期主题引用保留待核对，热力图只计已归类条目。站内开发复用需求进度已有的合并凭据，链接指向原 PR。仅展示有证据的合并结果，覆盖保持不完整，候选、实际发布、验收和其余开发日期未知。

运行 `node src/personal-daily/activity-review/check-journal-mapping.mjs` 或以 `RUN_ACTIVITY_OWNER_BROWSER=1` 运行 `test/activity-owner-browser.integration.test.ts`。浏览器使用合成日记响应。正式发布、本人实际记录读回、主题覆盖及完整开发来源仍由既有流程分别验证。
